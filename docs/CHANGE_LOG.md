# 변경 이력

공개 가능한 결과 중심 변경 요약이다. 항목은 일자 단위이며 최신 항목을 위에 둔다.

## 2026-07-28 — 공개·비공개 문서 레이어 정리

### Docs

- 공개 문서와 내부 작업 문서의 분리 기준을 적용했다.
- 변경 이력과 트러블슈팅을 일자 단위 항목으로 정리했다.

## 2026-07-23 — 릴리스 정비와 이벤트 수명주기 처리

### Added

- API 응답에 JSON 유효성 가드와 안정적인 식별자를 도입했다.
- 종료된 이벤트의 수명주기를 상태에 따라 처리하도록 했다.

### Changed

- 릴리스 런타임 의존성을 갱신했다.

### Fixed

- 폼 라벨과 디코딩 텍스트의 접근성 이름을 개선했다.

## 2026-06-25 — lint 경고 정리

### Changed

- 누적된 lint 경고를 정리하고 저장소 구성을 정돈했다.

## 2026-06-16 — lint 게이트 복구와 토큰 드리프트 가드

### Added

- 빌드 전 단계에서 공통 디자인 토큰의 해시를 검증하는 드리프트 가드를 도입했다.

### Fixed

- 프레임워크 major 전환으로 무력화됐던 lint 게이트를 flat config 마이그레이션으로 복구했다.

## 2026-06-13 — 부트 스킵과 접근성 글루

### Added

- 부트 시퀀스 건너뛰기를 추가했다.
- 선택·포커스 글루 토큰과 모션 축소 설정 가드를 적용했다.

## 2026-06-12 — STANN OS LIVE 표면 정렬

### Added

- 공통 토큰 정본을 도입했다. 비색상 토큰만 소비하고 색상은 이벤트 스킨을 유지한다.
- 라벨용 모노스페이스 글루를 도입하고 타이틀 폰트는 유지했다.
- 세 표면을 상호 연결하는 SIGNAL_NET 링크와 HUB 진입점을 추가했다.

### Changed

- 페이지 헤더 라벨 문법과 자간 토큰을 정렬했다.

## 2026-05-09 — 지난 이벤트 레이블 처리

### Fixed

- 홈 이벤트 레이블이 시각 경과 후 지난 이벤트 표기로 전환되도록 했다.

## 2026-05-08 — 게스트 신청 기간 경계 보정

### Fixed

- 게스트 신청을 이벤트 시작 시각까지 허용하도록 기간 판정을 보정했다.

## 2026-04-25 — 모바일 장식선 반응형 보정

### Fixed

- 홈 타이틀 장식선과 초대장 구분선이 모바일에서 깨지던 문제를 반응형 여백과 감지 로직 강화로 해결했다.

## 2026-04-24 — SIGNAL 구독 페이지와 타임존 표시

### Added

- 소식 구독 페이지를 신설하고 동의 UI를 컴포넌트로 분리했다.

### Changed

- 전송 로그 타임스탬프를 방문자의 로컬 타임존 기준으로 표시하도록 했다.
- 홈 모듈 카운트를 구독 페이지 추가에 맞춰 갱신했다.

### Fixed

- 디코딩 텍스트가 모바일에서 잘리던 문제를 해결했다.

## 2026-04-22 — 라인업 등록과 시드 데이터 정리

### Added

- 신규 이벤트 라인업을 등록하고 게스트 신청 흐름을 개선했다.

### Security

- 시드 데이터가 이력에 남지 않도록 제거하고 무시 정책을 반영했다.

## 2026-04-21 — 인증 코드 기반 게스트 신청과 상태 대시보드

### Added

- DJ별 인증 코드와 게스트 정원 시스템을 도입했다.
- 인증 코드로 초대인이 자동 완성되도록 하고 폼 순서를 개선했다.
- 게이트 페이지에 이벤트 소개글과 포스터 표시를 추가했다.

### Changed

- 상태 페이지를 실제 이벤트 데이터 기반 대시보드로 전면 교체했다.
- 이벤트 소개글을 줄 단위 디코딩 애니메이션으로 표현했다.

### Fixed

- 전송 로그의 멀티라인 메시지가 잘리던 문제를 해결했다.
- 모바일 입력 포커스 시 화면이 확대되던 동작을 막았다.
- 페이지 헤더 강조 효과, 복귀 링크 접근성, 상태 아이콘 중복, 라인업 컬럼 줄바꿈을 정리했다.

## 2026-04-20 — 폰트 토큰 일관화와 신청 폼 확장

### Added

- 인스타그램 입력란에 고정 접두어와 안내 문구를 추가했다.
- 게스트 신청 폼에 초대인 선택과 코드 사전입력 링크 지원을 추가했다.
- 선택 항목인 마케팅 수신 동의를 추가했다.
- 서버 상태 캐싱 라이브러리를 도입해 모바일 뒤로가기 동작을 최적화했다.

### Changed

- 전 페이지의 임의 폰트 크기를 토큰으로 치환해 일관화했다.
- 영문 번역을 훅 기반 구조로 통합 관리하도록 바꿨다.

### Fixed

- 모바일 반응형 레이아웃을 안정화했다.

## 2026-04-19 — 폰트 토큰 시스템과 공통 폼 컴포넌트

### Changed

- 신청·전송 폼과 공통 UI 컴포넌트를 토큰 기반으로 이전했다.

## 2026-04-17 — 렌더링 안정화

### Fixed

- 크기 관찰자 피드백 루프를 제거했다.
- 모바일 반응형과 레이아웃을 통일했다.

## 2026-04-15 — 코드 검증과 타이포그래피 안정화

- 타이포그래피 시스템을 최종 안정화했다.

## 2026-04-14 — 라인업 아코디언과 타이포그래피 시스템

### Added

- 라인업에 아티스트 소개 아코디언과 다국어 표시를 추가했다.
- 전역 시맨틱 타이포그래피 시스템을 구축했다.

### Fixed

## 2026-04-13 — 폼 상호작용 보정

### Added

- 전송 로그 페이지네이션의 높이 전환을 자연스럽게 개선했다.

### Fixed

- 모바일에서 버튼 텍스트 디코딩 시 높이가 튀는 문제를 해결했다.
- 전송 중 버튼 상태와 클라이언트 제출 가드를 공통 컴포넌트로 정리했다.

## 2026-04-11 — 다국어 지원과 폰트 적용

### Added

- 언어 컨텍스트와 언어 토글을 도입하고 전 페이지에 한국어·영어 번역을 적용했다.
- 부트 시퀀스에 언어 선택 단계를 통합했다.
- 높이 애니메이션 컴포넌트를 추가했다.
- 타이틀·본문용 로컬 폰트를 적용했다.

### Fixed

- 신청 페이지의 잘못된 태그 중첩으로 발생하던 하이드레이션 오류를 해결했다.

## 2026-04-10 — Cloudflare 배포 인프라와 프레임워크 업그레이드

### Added

- Cloudflare Workers와 D1 기반 배포 인프라를 구성하고 CI/CD를 연결했다.
- 노드 식별자 자동 부여, 게이트 접근 요청 페이지, 카운트다운, 전송 로그 페이지네이션을 추가했다.

### Changed

- 이벤트·아티스트 스키마를 식별자와 JSON 데이터 구조로 유연화했다.
- Next.js를 16 계열로 업그레이드하고 Worker 어댑터 호환성을 맞췄다.
- 컨테이너 베이스 이미지를 런타임 호환성에 맞게 교체했다.

### Fixed

- 엣지 런타임 설정과 번들링 충돌, 미들웨어 설정 누락 등 배포 초기 빌드 문제를 정리했다.
- 부트 시퀀스와 슬립 모드의 레이아웃을 통일했다.

## 2026-04-09 — 디자인 시스템 통합

### Fixed
