# terminal-2 개요

terminal-2는 STANN OS의 LIVE 표면이다.

- 표면 역할: LIVE
- SYS.ID: TM-02
- 공개 URL: `https://terminal.stann.kr`
- repo: `/Users/stann/Dev/terminal-2`

## 현재 정렬 기준

- STANN OS 공통 토큰: `app/stann-os.css`
- 이벤트 스킨 팔레트: terminal-2 고유 레이어로 유지
- 공통 glue: JetBrains Mono 라벨, `[ /PATH ]` 라벨 문법, `tracking-label`, `SIGNAL_NET`, `focus-visible`, `selection`, reduced-motion
- 3표면 링크: HUB(`stann.kr`) / ARCHIVE(`lumo.stann.kr`) / LIVE(`terminal.stann.kr`)
